# 📊 Finance OS

**Finance OS** is a modern, responsive, and beautifully designed personal finance dashboard. It features a glassmorphism aesthetic with a dark/light mode toggle, dynamic financial summary cards, an AI-assisted insights panel, and a fully mobile-first, collapsible navigation system.

## ✨ Key Features
- **Responsive Navigation:** Features a slide-out hamburger menu on mobile and an auto-collapsing icon-only sidebar on desktop to maximize your screen real estate.
- **Glassmorphism UI:** Stunning, frosted-glass design components with vibrant gradients and smooth micro-animations.
- **Theme Engine:** Instantly toggle between Dark Mode and Light Mode, with your preference automatically saved.
- **Dynamic Transactions:** A beautifully formatted transaction list that gracefully adapts from a desktop table into mobile-friendly stacked cards.
- **Interactive Chatbot:** A built-in AI Insight chat panel that slides out seamlessly on any device size.
- **Quick Actions:** Click your avatar to toggle the sidebar, or click the "Finance OS" logo to instantly refresh the dashboard.

## 🛠️ Tech Stack
- **HTML5:** Semantic, accessible structure.
- **CSS3:** Vanilla CSS featuring CSS Variables (custom properties), Flexbox, CSS Grid, and custom animations. No external UI frameworks (like Bootstrap or Tailwind) were used, ensuring complete design control.
- **Vanilla JavaScript:** Powers the theme toggling, sidebar mechanics, modal popups, and dynamic UI rendering without the overhead of heavy frameworks.

## 🚀 How to Run Locally
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Open `index.html` directly in any modern web browser (Chrome, Safari, Firefox, Edge). 
*(Note: For the best experience and to avoid local CORS restrictions if you eventually add fetch APIs, it is recommended to run a local server like Live Server in VS Code).*

## 📱 Mobile-First Design
Finance OS is strictly designed with mobile users in mind. The UI dynamically detects screen width to transform complex desktop tables into readable touch-friendly cards, and the floating action buttons ensure you can always add expenses or scan receipts with a single thumb tap.
